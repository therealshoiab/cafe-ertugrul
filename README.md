# Cafe Ertugrul — Official Restaurant Website

An authentic, ultra-responsive 3-page website built for **Cafe Ertugrul** (located at Solina Bazar, Airport Rd, Srinagar, Jammu & Kashmir 190008).

![Cafe Ertugrul Hero](/public/images/hero.png)

## 👑 Key Features

- **Page 1: Home & About (Main Page)**
  - Hero banner with royal background, tagline, and call-to-actions.
  - Heritage story of Cafe Ertugrul, Solina Bazar locale, Kashmiri Wazwan & Ottoman hospitality.
  - Chef's recommendations highlight cards for Kashmiri Biryani, Mutton Kanti, and Saffron Almond Shake.
  - Guest reviews & key restaurant highlights.

- **Page 2: Interactive Menu Page**
  - All **16 categories** with 91 dishes:
    1. Biryani And Rice (12)
    2. Non Veg Pizza (6)
    3. Veg Pizza (8)
    4. House Of Tandoor (3)
    5. Momo Hut (5)
    6. Main Course Non Veg (9)
    7. Main Course Veg (8)
    8. Kanti And Kebab (4)
    9. Kathi Rolls (3)
    10. Mocktails And Shakes (7)
    11. Snacks Light Munchies (8)
    12. Noodles (4)
    13. Salad (2)
    14. Bread And Naan (4)
    15. Pasta (2)
    16. Combo's (Save Extra Upto 30% Off) (6)
  - Real-time search bar & Veg / Non-Veg filter toggle.
  - Interactive takeaway tray with live INR price calculation.

- **Page 3: Contact & Location Page**
  - Clickable direct phone call link: **`07006609580`** (`+91 70066 09580`).
  - Interactive Google Maps location embed centered on Airport Rd, Solina Bazar, Srinagar.
  - Table reservation & inquiry form.
  - Embedded social media cards for Instagram ([@cafe.ertugrul](https://www.instagram.com/cafe.ertugrul)) and Facebook ([cafe.ertugrul](https://www.facebook.com/cafe.ertugrul)).

- **📞 Floating Dial Button**: Sticky quick-call button with pulse glow effect available on all pages.
- **📱 Auto-Responsive Viewports**: Responsive layout auto-adapts for Mobile Phones, Tablets, and Laptops/Desktops.

---

## 🛠️ Tech Stack & Setup

- **Core**: React 18 + Vite
- **Styling**: Modern CSS variables, glassmorphism, fluid typography (`clamp()`), and responsive grid layouts.
- **Icons**: Lucide React + custom SVG icons.

### Development Commands

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build
```
